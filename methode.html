LE FIL LIBRE

Notre méthode.

Le site ne garde que les informations publiées depuis moins de six heures. Le fil est régénéré automatiquement et les entrées trop anciennes disparaissent de l’affichage.

Ce qui remonte

Le filtre privilégie les décisions publiques, les institutions, la justice, les administrations, les lois, les budgets et les actes de pouvoir. Les faits divers, le sport et les sujets people sont écartés autant que possible.

Un lien du fil est une porte vers la source d’origine. Ce n’est pas, à lui seul, une brève vérifiée ou une validation éditoriale du titre publié par cette source.

Sources et fraîcheur

Le robot relève plusieurs flux d’actualité publics. Chaque entrée conserve son média d’origine, son lien et son heure de publication. Le navigateur applique ensuite la règle des six heures avant affichage.

Pourquoi GitHub Pages

Cette version est volontairement statique : elle peut être servie gratuitement par GitHub Pages sans serveur permanent. Les données du fil sont renouvelées séparément par une automatisation du dépôt.
